# Singer-Songwriter Website (React)

This project is a React + Vite starter website for a singer-songwriter.

## Configuration

Update `src/siteConfig.js` to customize the site content:

- `artistName`
- `tagline`
- `bio`
- `contact.email`
- `contact.phone`
- `links` (streaming/social links)

The homepage reads these values directly from the config file.

## Run

```bash
npm install
npm run dev
```
