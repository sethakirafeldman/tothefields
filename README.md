# Singer-Songwriter Website (React)

This project is a React + Vite starter website for a singer-songwriter.

## Included pages

The starter now includes common artist-site pages:

- Home
- About
- Music
- Shows
- Press
- Contact

Navigation is hash-based, so the pages work without adding a routing dependency or extra static hosting setup.

## Configuration

Update `src/siteConfig.js` to customize the site. Each page has its own config block under `pages`, for example:

- `pages.home`
- `pages.about`
- `pages.music`
- `pages.shows`
- `pages.press`
- `pages.contact`

You can edit labels, copy, links, releases, shows, quotes, and contact details there without touching the app code.

## Run

```bash
npm install
npm run dev
```
